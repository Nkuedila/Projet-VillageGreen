entité Catégories

Données

Nom de l'Attribut Type Description
id int Identifiant unique de la catégorie (clé primaire).
nom string(255) Nom unique de la catégorie.
image string(255) Chemin ou URL de l’image de la catégorie.
parent_id int (nullable) Référence à la catégorie parent.
categories Collection Liste des sous-catégories associées.
produits Collection Liste des produits appartenant à cette catégorie.

condition

ID condition
condition 1 Une catégorie doit avoir un nom unique.
condition 2 Une catégorie peut être une sous-catégorie d'une autre catégorie.
condition 3 Une catégorie peut contenir plusieurs sous-catégories.
condition 4 Une catégorie peut contenir plusieurs produits, mais un produit appartient à une seule catégorie.
condition 5 Lorsqu'une catégorie est supprimée, ses sous-catégories sont également supprimées (CASCADE).
condition 6 Une catégorie doit obligatoirement avoir une image associée.

entité Fournisseur

Données

Nom de l'Attribut Type Description
id int Identifiant unique du fournisseur (clé primaire).
nom string(255) Nom unique du fournisseur.
adresse string(255) Adresse complète du fournisseur.
telephone string(20) Numéro de téléphone du fournisseur.
produits Collection Liste des produits fournis par fournisseur.

condition

ID condition
condition 1 Un fournisseur doit avoir un nom unique.
condition 2 Un fournisseur doit avoir un adresse valide.
condition 3 Un fournisseur doit avoir un numéro de téléphone valide (20 caractères max).
condition 4 Un fournisseur peut fournir plusieurs produits.
condition 5 Lorsqu'un fournisseur est supprimé, les produits liés ne doivent pas être supprimés mais désassociés.

entité Produits

Données

Nom de l'Attribut Type Description
id int Identifiant unique du produit (clé primaire).
nom string(255) Nom du produit.
description text Description détaillée du produit.
prix int Prix du produit en centimes.
stock int Quantité disponible en stock.
created_at datetime Date et heure de création du produit.
reference_fournisseur string(100) Référence fournisseur du produit.
image string(255) URL de la photo du produit.
categories relation Catégorie du produit.
fournisseur relation Fournisseur du produit.

condition

ID condition
condition 1 Un produit doit avoir un nom unique.
condition 2 Le prix d'un produit doit être supérieur à zéro.
condition 3 Le stock d'un produit ne peut pas être négatif.
condition 4 Un produit appartient à une seule catégorie.
condition 5 Un produit peut être lié à un seul fournisseur.
condition Lorsqu'un produit est supprimé, ses commandes et livraisons doivent être conservées mais désassociées.

entité Users

Données

Nom du champ Type Description Contraintes
id Integer Identifiant unique de l'utilisateur Auto-incrémenté, clé primaire
email String (180) Adresse email de l'utilisateur Unique, obligatoire
roles Array Rôles attribués à l'utilisateur Valeur par défaut : ROLE_USER
password String Mot de passe hashé Obligatoire
nom String (255) Nom de l'utilisateur Obligatoire
prenom String (255) Prénom de l'utilisateur Obligatoire
adresse String (255) Adresse postale Obligatoire
codepostal String (10) Code postal Format numérique
ville String (150) Ville Obligatoire
created_at DateTimeImmutable Date de création du compte Valeur par défaut : CURRENT_TIMESTAMP
userstype Relation Type d'utilisateur Peut être null
numeroSiret Integer Numéro SIRET (entreprise) Peut être null

condition

Un utilisateur ne peut pas avoir la même adresse email qu’un autre (contrainte d’unicité).
Le mot de passe est stocké de manière hashée(cacher) pour assurer la sécurité.
Les utilisateurs qui sont des admins, on tous un role qui leur est spécifique ROLE_USER.
Le champ numeroSiret est uniquement pour les utilisateurs du type professionnels .
même un utilisateur est supprimé, ses commandes ne doivent pas être supprimées automatiquement.

entité Commande

Données

Nom du champ Type Description Contraintes
id Integer Identifiant unique de la commande Auto-incrémenté, clé primaire
reference String (50) Référence unique de la commande Obligatoire
created_at DateTimeImmutable Date de création de la commande Valeur par défaut : CURRENT_TIMESTAMP
reduction Float Réduction appliquée sur la commande Valeur par défaut : 0.0
etat String (255) Statut actuel de la commande Obligatoire
dateFacture Date Date d’émission de la facture Peut être null
adresseFacture String (255) Adresse de facturation Obligatoire
dateLivraison DateTimeImmutable Date prévue pour la livraison Peut être null
adresseLivraison String (255) Adresse de livraison Obligatoire
users Relation Utilisateur ayant passé la commande Relation ManyToOne avec `Users`
coefficient Float Coefficient de marge appliqué à la commande Obligatoire
total Decimal (10,2) Montant total de la commande Obligatoire
datePaiement DateTime Date du paiement Peut être null

condition

pour qu'une commande puisse passer il doit y avoir une connexion de la par d'un utilisateur donc l'utilisateur doit se connecté.
Le champ reduction ne peut pas être négatif.
Une commande ne peut être facturée que si elle est en statut "Validée" ou supérieur.
L’adresse de livraison et l’adresse de facturation doivent être renseignées obligatoirement.
Une commande ne peut être livrée que si son paiement est validé.
Le total doit être calculé automatiquement en fonction des produits et de la réduction.
